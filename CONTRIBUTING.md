# Contributing to Echo

Echo is the owner's maintained fork and permits owner-requested AI-assisted
contributions. Start with the [contributor handbook](documentation/echo/contributing/README.md)
and [AGENTS.md](AGENTS.md). The handbook includes exact build/test/install commands,
source maps, complete app/script templates, current device state and task handoffs.

The maintained branch is **studio**, the sole local/fork branch by owner request.
Use focused commits on studio, preserve API87.1/dependency pins/data, and check CI
for the exact pushed commit. Keep software, device UI and physical validation
claims separate. Preserve component licenses and attribution; never commit secrets
or private captures.

The original [upstream contribution notice](documentation/UPSTREAM_CONTRIBUTING.md)
and [upstream agent policy](documentation/UPSTREAM_AGENT_POLICY.md) are archived
for provenance. They are not this fork's contribution policy. Do not submit this
fork's AI-authored work upstream under those policies.
